# MERN Stack Notes App

A full-stack MERN Notes Application with:

- User Authentication
- Register & Login
- JWT Authentication
- Notes Dashboard
- Add Notes
- Edit Notes
- Delete Notes
- Attractive UI Design

---

# 🚀 Tech Stack

## Frontend
- React.js
- Axios
- React Router DOM

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs

---

# 📂 Project Structure

```bash
MERN-STACK

```

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/adarsh54398/mern-stack-task5.git
```

---

## 2️⃣ Backend Setup

```bash
cd backend
npm install
npm start
```

Backend runs on:

```bash
http://localhost:5000
```

---

## 3️⃣ Frontend Setup

Open new terminal:

```bash
cd frontend
npm install
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```
